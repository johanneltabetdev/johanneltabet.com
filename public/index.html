About

I've been building for the web since 2013, coming from a design background. For about ten years I worked freelance for agencies and brands.

I've worked for Louis Vuitton since 2019: first as a freelance front-end developer on the e-commerce revamp, then in-house from 2023, where I work on the front-end architecture, from design tokens, component APIs and accessibility to SSR, build tooling and CI/CD.

I enjoy working between design and engineering, and learning how systems grow over time.

Selected work

Design system

I lead the design system on the web platform: Vue and agnostic components, design tokens from Figma to code, and documentation in Storybook. I work with designers and product people to give product teams the components and documentation they need, and I help other IT teams adopt it.

Accessibility

Accessibility referent for the web platform. I help with audits, code reviews and fixes. I built an automated testing suite for the web platform, and I try to make WCAG a shared practice by building it into the design system's component APIs.

Revamp and Vue 3 migration

Worked on the rebuild of the front-end of Louis Vuitton's e-commerce website as a headless Nuxt application (2019–2022), with a component library and design system in Storybook, Jest, a BFF layer and Akamai at the edge. Helped the front-end teams learn Vue. Later worked on the migration of a large codebase from Vue 2 to Vue 3.

Architecture

  • ADRs and technical architecture documents (TAD), shared with product teams and partners such as Akamai
  • SSR, build tooling and CI/CD
  • Versioned private packages and a modular architecture
